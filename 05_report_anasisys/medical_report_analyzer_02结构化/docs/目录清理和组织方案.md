## 📜 文件管理规则

### 命名规则
1. **文件名使用英文**：避免中文文件名
2. **使用下划线分隔**：如 `quality_validator.py`
3. **明确文件用途**：
   - `test_*.py` - 测试文件
   - `debug_*.py` - 调试文件
   - `config_*.py` - 配置文件
   - `*_guide.md` - 指南文档

### 目录规则
1. **按功能分类**：源码、测试、文档、数据分离
2. **按生命周期分类**：开发中、已完成、已归档
3. **按访问频率分类**：常用、偶用、归档

### 清理规则
1. **定期清理**：每月清理一次临时文件
2. **版本控制**：重要文件必须在git中
3. **备份归档**：过期文件移动到archive/
4. **文档更新**：修改目录结构时更新README
