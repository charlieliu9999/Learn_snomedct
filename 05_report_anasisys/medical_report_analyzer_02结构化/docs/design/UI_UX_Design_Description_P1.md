# 医学影像智能分析与辅助报告系统 - P1 阶段 UI/UX 设计描述

本文档描述了医学影像智能分析与辅助报告系统 P1 阶段（核心功能上线）的用户界面 (UI) 和用户体验 (UX) 设计思路和关键要素。基于已定义的产品需求、用户故事和用例，本阶段的 UI/UX 设计重点聚焦于核心的报告撰写、编辑和管理功能，旨在提供清晰、高效、用户友好的操作体验。

## 1. 设计原则回顾

遵循项目整体 UI/UX 设计原则：

*   **用户中心**: 深入理解影像科医生、临床医生等核心用户的操作习惯和痛点。
*   **清晰直观**: 界面布局简洁明了，信息层级清晰，关键功能易于发现和使用。
*   **一致性**: 保持界面元素、交互模式和视觉风格在整个系统中的一致性。
*   **高效性**: 优化操作流程，减少不必要步骤，提升用户工作效率，特别是报告撰写效率。
*   **可访问性**: 考虑不同用户的需求，提供良好的可访问性支持。
*   **反馈及时**: 用户操作后提供清晰、及时的反馈。
*   **可定制性**: 考虑未来报告模板、快捷短语等的可定制需求。

## 2. 关键用户流程与界面描述

### 2.1 影像科医生撰写/编辑报告流程

**用户故事**: 作为影像科医生，我希望能够快速、准确地撰写结构化医学影像报告，并能方便地引用标准术语和模板。

**核心用例**: 撰写新的影像报告，编辑现有报告。

**流程描述**:
1.  医生从工作列表或通过搜索选择待撰写/编辑的影像检查。
2.  系统加载患者信息和影像信息，进入报告编辑界面。
3.  医生使用双向驱动编辑器进行报告撰写。
4.  编辑器提供结构化模板、快捷短语、术语联想输入等辅助功能。
5.  医生可以实时预览报告的结构化效果。
6.  完成撰写后，医生保存报告草稿或提交审核。

**界面描述**: **报告编辑界面**
*   **整体布局**: 采用三栏或双栏布局。
    *   左侧/顶部区域：患者基本信息、影像信息、历史报告链接等。
    *   中间区域：**双向驱动报告编辑器**。这是核心区域，占据主要空间。
    *   右侧/底部区域：辅助工具面板，包括：
        *   报告模板选择与应用。
        *   常用快捷短语列表与插入。
        *   SNOMED CT 等术语搜索、联想与插入（可能通过弹窗或侧边栏实现）。
        *   基础结构化分析结果预览（例如，已识别的术语列表）。
*   **双向驱动编辑器**: 
    *   上方区域：自由文本编辑框，支持富文本编辑功能（加粗、斜体、列表等）。
    *   下方区域：结构化数据展示区域，实时同步上方文本中识别出的结构化信息（如检查部位、诊断结论、体征等），或通过结构化输入反向生成文本。
    *   两者之间通过高亮、标记等方式进行关联。
*   **交互**: 
    *   输入文本时，下方结构化区域实时更新。
    *   在下方结构化区域修改数据，上方文本相应更新。
    *   点击下方结构化区域的条目，上方文本中对应的位置高亮。
    *   通过辅助工具面板快速插入模板、短语、术语。
*   **操作按钮**: 保存草稿、提交审核、预览、导出等。

### 2.2 临床医生查阅报告流程

**用户故事**: 作为临床医生，我希望能够方便快捷地查阅患者的医学影像报告。

**核心用例**: 查阅影像报告。

**流程描述**:
1.  临床医生通过患者信息或检查信息搜索报告。
2.  系统展示报告列表。
3.  医生选择报告进行查阅。
4.  系统展示报告详情，包括结构化和非结构化内容。

**界面描述**: **报告查阅界面**
*   **整体布局**: 清晰展示报告内容。
*   **报告内容展示**: 
    *   优先展示结构化报告内容，以结构化的方式呈现关键信息（如检查方法、检查所见、诊断结论）。
    *   同时提供原始非结构化文本报告的查看选项。
    *   可能包含影像缩略图或链接。
*   **交互**: 提供报告的打印、导出功能。

### 2.3 管理员管理报告模板流程

**用户故事**: 作为管理员，我希望能够方便地创建、编辑和管理报告模板。

**核心用例**: 创建模板，编辑模板，删除模板，发布/下线模板。

**流程描述**:
1.  管理员进入模板管理界面。
2.  系统展示现有模板列表。
3.  管理员可以选择创建新模板、编辑现有模板、删除模板或修改模板状态。
4.  创建/编辑模板时，使用专门的模板编辑器，支持定义结构化字段和默认文本。
5.  保存并发布模板。

**界面描述**: **报告模板管理界面**
*   **整体布局**: 列表页 + 详情/编辑页。
*   **模板列表页**: 展示模板名称、创建者、状态（草稿/已发布）、创建时间等信息，提供搜索、过滤功能。
*   **模板编辑页**: 
    *   提供一个类似于报告编辑器的界面，但侧重于定义模板结构。
    *   可以定义报告的各个章节（如检查方法、检查所见、诊断结论）。
    *   在章节内定义结构化字段（如部位、大小、性质），并关联可能的 SNOMED CT 概念。
    *   设置默认文本或占位符。
    *   提供保存、预览、发布按钮。

### 2.4 系统管理员管理用户与权限流程

**用户故事**: 作为系统管理员，我希望能够管理系统用户及其访问权限。

**核心用例**: 创建用户，编辑用户信息，分配角色/权限，禁用/启用用户。

**流程描述**:
1.  系统管理员进入用户管理界面。
2.  系统展示用户列表。
3.  管理员可以创建新用户、编辑用户信息、分配角色和权限。

**界面描述**: **用户管理界面**
*   **整体布局**: 列表页 + 详情/编辑页。
*   **用户列表页**: 展示用户名、角色、所属科室、状态等信息，提供搜索、过滤功能。
*   **用户详情/编辑页**: 表单形式，用于输入和修改用户基本信息、分配角色（如影像科医生、临床医生、管理员、系统管理员）和细粒度权限。

## 3. 视觉风格指南 (初步)

本阶段不强制定义完整的视觉风格指南，但建议遵循以下初步原则：

*   **色彩**: 采用专业、稳重的色调，如蓝色、灰色为主，辅以少量强调色。
*   **字体**: 选择清晰易读的无衬线字体。
*   **图标**: 使用简洁、直观的图标。
*   **布局**: 采用响应式布局，确保在不同屏幕尺寸下的可用性。
