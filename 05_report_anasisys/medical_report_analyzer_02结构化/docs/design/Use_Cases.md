## 核心用例列表

### UC001: 影像科医生撰写新的影像报告

*   **用例名称:** 撰写新的影像报告
*   **参与者:** 影像科医生（初级/规培/高级）
*   **前置条件:**
    *   医生已登录系统。
    *   患者的检查信息已从PACS/RIS同步至本系统（或可手动创建）。
*   **基本流程:**
    1.  医生选择一个待报告的检查（或创建一个新的报告任务）。
    2.  系统根据检查类型（如CT头部平扫、MRI膝关节）自动加载或推荐合适的报告模板。
    3.  医生在双向驱动编辑器中查看患者影像。
    4.  医生在编辑器的“影像所见”区域输入描述性文字。
    5.  系统根据输入内容，实时提供SNOMED CT术语、标准描述短语、同义词等智能提示和自动补全建议。
    6.  医生选择或采纳系统建议，或继续手动输入。
    7.  医生可以在影像上进行测量、标注关键发现，并将截图或标注信息嵌入报告相应位置。
    8.  医生在编辑器的“诊断意见”区域输入诊断结论。
    9.  系统可根据“影像所见”内容，辅助推荐可能的诊断方向或相关鉴别诊断。
    10. 医生完成报告撰写，可选择“暂存”或“提交审核”。
*   **扩展流程:**
    *   **3a. 模板选择:** 如果系统推荐模板不适用，医生可以手动搜索并选择其他可用模板。
    *   **4a. 语音输入:** 医生可以通过语音识别功能输入描述内容。
    *   **7a. 历史影像对比:** 医生可以调阅患者的历史影像及报告进行对比分析。
    *   **10a. 结构化数据校验:** 提交前，系统可对报告进行初步的结构化完整性、逻辑一致性检查，并提示潜在问题。
*   **后置条件:**
    *   报告被保存（状态为“草稿”或“待审核”）。
    *   相关的结构化数据被提取并存储。
*   **关联用户故事:** US001, US002, US003, US004, US005

### UC002: 高级影像科医生审核报告

*   **用例名称:** 审核影像报告
*   **参与者:** 高级影像科医生（主任）
*   **前置条件:**
    *   高级医生已登录系统。
    *   至少有一份状态为“待审核”的报告。
*   **基本流程:**
    1.  高级医生进入报告审核列表，查看待审核报告。
    2.  选择一份报告进行审核，系统展示报告内容及相关影像。
    3.  高级医生审阅报告的“影像所见”、“诊断意见”等内容。
    4.  如果报告无误，高级医生选择“审核通过并签发”。
    5.  如果报告需要修改，高级医生可以直接在报告上进行编辑修改，或添加批注说明。
    6.  修改后，高级医生选择“审核通过并签发”；或者，如果需要初级医生进一步修改，则选择“退回修改”并填写退回原因。
*   **扩展流程:**
    *   **3a. 查看修改痕迹:** 如果报告被多次修改，可以查看历史版本和修改痕迹。
*   **后置条件:**
    *   报告状态更新为“已签发”或“已退回”。
    *   签发后的报告可供临床医生查阅。
*   **关联用户故事:** US006

### UC003: 临床医生查阅影像报告

*   **用例名称:** 查阅影像报告
*   **参与者:** 临床医生
*   **前置条件:**
    *   临床医生已登录系统（或通过HIS/EMR接口访问）。
    *   患者的影像报告已签发。
*   **基本流程:**
    1.  临床医生通过患者ID或其他标识查询患者的影像报告列表。
    2.  选择需要查阅的报告。
    3.  系统展示结构化的影像报告，突出显示关键发现和诊断结论。
    4.  如果报告中嵌入了影像标注，临床医生可以查看。
    5.  临床医生可以查看相关的原始影像（如果系统集成允许）。
*   **扩展流程:**
    *   **3a. 历史报告对比:** 临床医生可以方便地切换查看同一患者的历史影像报告。
*   **后置条件:**
    *   临床医生获取了所需的影像诊断信息。
*   **关联用户故事:** US009, US010

### UC004: 管理员管理报告模板

*   **用例名称:** 管理报告模板
*   **参与者:** 影像科医生（高级/主任）、医院信息科管理员（特定权限）
*   **前置条件:**
    *   用户已登录系统并拥有模板管理权限。
*   **基本流程:**
    1.  用户进入报告模板管理模块。
    2.  **创建新模板:**
        a.  选择“创建新模板”。
        b.  输入模板名称、适用的检查类型、科室等基本信息。
        c.  设计模板结构，包括章节（如检查方法、影像所见、诊断意见）、固定描述、可填写的字段、以及与SNOMED CT等术语体系的预关联。
        d.  保存模板。
    3.  **修改现有模板:**
        a.  选择一个现有模板进行编辑。
        b.  修改模板的结构、内容或关联。
        c.  保存修改。
    4.  **停用/启用模板:**
        a.  选择一个模板，设置其状态为“停用”或“启用”。
    5.  **设置默认模板:**
        a.  为特定的检查类型设置默认使用的模板。
*   **后置条件:**
    *   报告模板库得到更新。
    *   新的或修改后的模板可供报告撰写时使用。
*   **关联用户故事:** US007

### UC005: 系统管理员管理用户与权限

*   **用例名称:** 管理用户与权限
*   **参与者:** 医院信息科管理员
*   **前置条件:**
    *   管理员已登录系统。
*   **基本流程:**
    1.  管理员进入用户管理模块。
    2.  **创建新用户:** 输入用户信息（工号、姓名、科室等），分配初始密码和用户角色。
    3.  **修改用户信息:** 修改现有用户的基本信息、重置密码或调整用户角色。
    4.  **停用/启用用户:** 设置用户账户状态。
    5.  管理员进入角色与权限管理模块。
    6.  **定义角色:** 创建新的用户角色（如初级影像医生、高级影像医生、临床医生、模板管理员）。
    7.  **分配权限给角色:** 为每个角色勾选其可以访问的功能模块和操作权限（如报告创建、审核、模板管理等）。
*   **后置条件:**
    *   系统用户和权限配置得到更新。
*   **关联用户故事:** US013

### UC006: (高级功能) 科研人员检索结构化报告数据

*   **用例名称:** 检索结构化影像报告数据
*   **参与者:** 科研人员
*   **前置条件:**
    *   科研人员已登录系统并拥有数据检索权限。
    *   系统已积累了一定量的结构化影像报告数据。
*   **基本流程:**
    1.  科研人员进入科研数据检索模块。
    2.  构建检索查询条件，可选择的条件包括：
        *   时间范围
        *   患者年龄、性别等基本信息
        *   检查类型
        *   影像所见中的特定SNOMED CT术语或关键词（如“结节”、“占位”、“强化”）
        *   诊断意见中的特定疾病编码或关键词
        *   其他结构化字段
    3.  执行检索。
    4.  系统返回符合条件的病例列表（匿名化处理，仅显示研究相关信息和病例计数）。
    5.  科研人员可以查看统计结果或导出匿名化的数据集（需符合数据安全和伦理规定）。
*   **后置条件:**
    *   科研人员获得用于研究的病例数据或统计信息。
*   **关联用户故事:** US011, US012
